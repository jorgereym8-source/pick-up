# Pick up

App web minimalista para elegir al azar una carta de mi colección Pokémon TCG (Illustration Rares + Others), con la misma probabilidad para todas.

- **Pick**: botón *Pick Your Card*; las cartas ruedan de derecha a izquierda 3–5 s y se gira la elegida.
- **Colección**: Illustration Rare y Others, buscador y botón **+** para añadir cartas nuevas.
- **Ajustes**: elección automática (días, horas, frecuencia), notificaciones, exportar picks al Calendario, datos a mostrar (Nº, Expansión, Nº Pokédex), temas, colores, translucidez, fondo y 5 tipos de letra.

Se instala en el iPhone desde Safari → Compartir → *Añadir a pantalla de inicio*.
